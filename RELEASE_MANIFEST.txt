RecallZero v2 release manifest
==============================

Version: 0.3.1
Release date: 2026-08-17
Target: NVIDIA GB10 / DGX Spark-compatible Python 3.11-3.13 environment

Release focus: scientific-validity patch
- Add campaign-agnostic canonical defect families while preserving raw NIM failure modes.
- Partition by NHTSA component family and canonical defect family before semantic DBSCAN.
- Split DBSCAN density chains using complete-link cosine refinement.
- Add raw failure-mode purity, canonical defect-family purity, and cluster-distance diagnostics.
- Validate numerical severity deterministically: NHTSA source flags are authoritative for crash/injury/fatality/fire, and semantic safety indicators require explicit narrative support.
- Expose validated severity indicators and evidence provenance; unsupported LLM indicators do not affect the risk score.
- Replace lexical-only recall matching with structured component/defect/subsystem/consequence/semantic scoring plus campaign-reference sanity checks.
- Distinguish EARLY_ALERT_TARGET_UNMATCHED from true NO_EARLY_SIGNAL.
- Preserve leakage-safe post-hoc target matching and all existing anti-leakage checks.

Included capabilities:
- NHTSA complaint and recall ingestion with evidence-preserving normalization
- NVIDIA NIM structured complaint extraction and embedding integrations
- Deterministic heuristic and TF-IDF fallbacks for explicitly allowed/offline modes
- Component-family + canonical defect-family + DBSCAN + complete-link clustering
- Deterministic trend, persistence, severity, evidence and recall-gap risk scoring
- Structured visible-recall matching and leakage-safe Recall Time Machine historical replay
- Evidence critic and engineering brief
- FastAPI service and Safety Radar dashboard
- NeMo Agent Toolkit plugin tools and standalone native tool-calling workflow
- Optional legacy AIQ registration and current stock AI-Q data-source-registry patching

Offline validation:
- 42 automated tests passed; 1 optional NAT-runtime integration test skipped because `nat` is not installed in the build container
- Python compilation passed
- Synthetic end-to-end analysis and historical replay passed
- Scientific-validity regression coverage includes hypothetical-event rejection, severity source provenance, taxonomy separation, campaign-reference matching, HV power-loss recall matching, and Time Machine outcome semantics
