RecallZero v2 release manifest
==============================

Version: 0.3.2
Release date: 2026-08-17
Target: NVIDIA GB10 / DGX Spark-compatible Python 3.11-3.13 environment

Release focus: signal lineage and meta-detection scientific-validity patch
- Split defect representation into root-oriented failure_mechanism and driver-visible consequence_family axes.
- Preserve component/consequence child clusters while adding deterministic cross-component meta-signals for specific root mechanisms.
- Add stable signal lineage IDs across weekly replay snapshots.
- Enforce complete-link refinement using maximum sampled pairwise distance, not only p90 dispersion.
- Validate semantic severity in the incident context and reject negated, hypothetical, or background driving references.
- Replace cutoff-ending persistence with recent active-week density plus maximum consecutive active weeks.
- Add component-compatible dual-axis recall matching.
- Record top Time Machine candidates and post-hoc target scores only after each detector snapshot is frozen.
- Keep the 75-point alert threshold, risk weights, minimum evidence defaults, and anti-leakage boundary unchanged.

Included capabilities:
- NHTSA complaint and recall ingestion with evidence-preserving normalization
- NVIDIA NIM structured complaint extraction and embedding integrations
- Deterministic heuristic and TF-IDF fallbacks for explicitly allowed/offline modes
- Component/consequence child clustering + root-mechanism meta-signals + DBSCAN + complete-link refinement
- Deterministic trend, persistence, severity, evidence and recall-gap risk scoring
- Structured visible-recall matching and leakage-safe Recall Time Machine historical replay
- Evidence critic and engineering brief
- FastAPI service and Safety Radar dashboard
- NeMo Agent Toolkit plugin tools and standalone native tool-calling workflow
- Optional legacy AIQ registration and current stock AI-Q data-source-registry patching

Offline validation:
- 47 automated tests passed; 1 optional NAT-runtime integration test skipped because `nat` is not installed in the build container
- Python compilation passed
- Synthetic end-to-end analysis and historical replay passed
- Scientific-validity regression coverage includes hypothetical-event rejection, severity source provenance, taxonomy separation, campaign-reference matching, HV power-loss recall matching, and Time Machine outcome semantics
