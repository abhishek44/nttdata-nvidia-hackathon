RecallZero v2 release manifest
==============================

Version: 0.3.3a1
Release date: 2026-08-18
Target: NVIDIA GB10 compute system / Python 3.11-3.13 environment

Release focus: Scientific Slice A — isolated severity/taxonomy/evaluation correction
- Repair event-scoped severity false negatives for moving shutdown/stall/power-loss narratives.
- Preserve parked no-start/no-drive negatives through deterministic event-context checks.
- Add a narrow mechanism/consequence consistency guard that downgrades contradictory specific assignments to GENERAL/OTHER.
- Score recall consequence compatibility from the observed consequence-family distribution, not only the dominant meta label.
- Separate evaluation-only target-pattern recognition (`earliest_target_like_candidate_date`) from a qualified alert (`first_qualified_alert_date`).
- Keep alert threshold 75, all risk weights, 28/84-day windows, DBSCAN eps/min_samples, and anti-leakage rules unchanged.
- Explicitly defer the signal-fusion graph and meta-membership confidence rules to a later isolated experiment.

Included capabilities:
- NHTSA complaint and recall ingestion with evidence-preserving normalization
- NVIDIA NIM structured complaint extraction and embedding integrations
- Deterministic heuristic and TF-IDF fallbacks for explicitly allowed/offline modes
- Component/consequence child clustering + root-mechanism meta-signals + DBSCAN + complete-link refinement
- Deterministic trend, persistence, severity, evidence and recall-gap risk scoring
- Structured visible-recall matching and leakage-safe Recall Time Machine historical replay
- Evidence critic and engineering brief
- FastAPI service and Safety Radar dashboard
- NeMo Agent Toolkit plugin tools and standalone native tool-calling workflow
- Optional legacy AIQ registration and current stock AI-Q data-source-registry patching

Offline validation:
- 60 automated tests passed; 1 optional NAT-runtime integration test skipped because `nat` is not installed in the build container
- 13 new 0.3.3a slice tests cover the six named moving Mach-E positives, four named parked negatives, taxonomy guard, consequence-distribution matching, and dual Time Machine metrics
- Python compilation passed
- Synthetic end-to-end analysis and historical replay passed
- Wheel build and isolated-target installation passed

Non-claims:
